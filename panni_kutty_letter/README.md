# Panni Kuttyyyy — Digital Letter

A self-contained, mobile-first digital friendship letter.

## Run locally
Open `index.html` directly in a browser, or serve this folder with any static server.

## Deploy
Upload `index.html` to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static hosting provider.

## Easy customization
All letter copy is in `index.html`. Search for the section headings (`Why I made this`, `Your presence`, etc.) to edit text.

### Photos
Replace each `.photo-placeholder` with an `<img>` tag pointing to your photo, or keep the placeholders until you're ready.

### Music
The music toggle is intentionally OFF by default and does not autoplay. To add music, you can add an `<audio>` element and wire it to `musicBtn` in the small JavaScript block near the bottom.

No backend or database is required.
